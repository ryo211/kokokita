# ココキタ 機能概要書

> 最終更新: 2026-11-23(v3.6.3 時点)
>
> このドキュメントは、アプリ「ココキタ」の全体像を、開発者以外の人にも分かる言葉でまとめたものです。
> 技術的な補足は「💡技術メモ」として必要なところだけ書いています。
> **機能を追加・変更したときは、このドキュメントも必ず更新してください。**(ルールは [CLAUDE.md](../CLAUDE.md) を参照)

## 1. ココキタとは

**「今ここに来た」をワンタップで記録できる、iPhone 向けの訪問記録アプリ**です。

ボタンを押すと、GPS で取得した現在地と日時がその場で記録されます。写真・メモ・一緒に行った人などを添えて、自分だけの「行った場所の記録帳」を作れます。

さらに、アニメや映画の舞台(いわゆる「聖地」)をめぐる **聖地巡礼** を楽しむための機能もあります。コースに登録されたスポットを訪れて記録すると、スタンプがもらえます。

### ココキタの特長

| 特長 | 内容 |
|---|---|
| ワンタップ記録 | ボタンひとつで、今いる場所と日時を記録 |
| 「本当に行った」の証明 | その場で GPS を使って作った記録には「証明付き」の印が付き、後から改ざんされていないことを確認できる |
| 聖地巡礼・スタンプラリー | コースのスポットを訪れるとスタンプがもらえる。何人目の到達者かも分かる |
| 後から整理しやすい | ラベル・旅行・メンバーで分類し、一覧・地図・カレンダーで振り返れる |
| 端末内に保存 | 記録は基本的に iPhone の中に保存される |

- 対応 OS: iOS 17 以上
- 対応言語: 日本語・英語

## 2. 2つのモード

ココキタには、使い方の違う **2つのモード** があります。初回起動時のオンボーディングで紹介され、画面下のボタンでいつでも切り替えられます。

| モード | こんな人向け | 主な画面 |
|---|---|---|
| **記録モード** | 行った場所を日記のように残したい人 | ホーム / 記録 / ココキタボタン / メニュー |
| **巡礼モード** | 聖地巡礼やスタンプラリーを楽しみたい人 | ホーム / コース / スポット / スタンプ |

どちらのモードでも、中央の「ココキタ」ボタンで現在地を記録できます。記録データは両モードで共通です。

## 3. 画面構成

### 3.1 記録モード

```
┌─────────────────────────────────┐
│                                 │
│          (各タブの画面)          │
│                                 │
├─────────────────────────────────┤
│ ホーム │ 記録 │ [ココキタ] │ メニュー │ ← タブバー
│                     [巡礼モードへ] │
└─────────────────────────────────┘
```

| タブ | できること |
|---|---|
| **ホーム** | 「現在地を記録する」ボタンと、最近の記録をカードで表示 |
| **記録** | すべての記録を **一覧 / 地図 / 日付(カレンダー)** で切り替えて表示。検索や絞り込みもここで行う。右下の「＋追加」ボタンから後付け記録を作れる |
| **ココキタ(中央ボタン)** | 現在地を取得して、すぐに記録を作る |
| **メニュー** | ラベル・旅行・メンバーの管理、ゴミ箱、設定など |

### 3.2 巡礼モード

| タブ | できること |
|---|---|
| **ホーム** | 巡礼の始め方の案内、コース一覧の入口、近くのスポット・行ったスポット・お気に入りスポットの表示。右上から設定を開ける |
| **コース** | コースを探して詳細を見る。地図上にスポットを表示 |
| **スポット** | すべてのコースのスポットを「近く / お気に入り / 行った / 都道府県別 / フォルダ」で一覧表示 |
| **スタンプ** | 集めたスタンプを一覧表示 |

## 4. 機能詳細

### 4.1 現在地の記録(ココキタ)

アプリのいちばん基本の機能です。

1. 「ココキタ」ボタンをタップ
2. GPS で現在地を取得(最大30秒ほど)
3. 記録が作られ、次にやることを選べる
   - **そのまま保存**: 後からいつでも編集できる
   - **情報を入力**: タイトル・メモ・写真などを入力する
   - **ココカモ**: 周辺の施設から選ぶ(4.2 参照)

記録に付けられる情報:

| 項目 | 内容 |
|---|---|
| タイトル・メモ | 自由入力 |
| 写真 | 1件の記録につき最大4枚(カメラ撮影 / フォトライブラリ) |
| 施設情報 | 施設名・住所・電話番号・カテゴリ |
| ラベル | 色付きのタグ。自由に作れる(例:「カフェ」「お気に入り」) |
| 旅行 | 旅行やおでかけ単位でまとめる |
| メンバー | 一緒に行った人 |
| ブック | 記録をまとめる「ノート」(4.10 参照) |

「過去の記録からコピー」で、以前の記録の内容を流用することもできます。

> **位置情報の偽装対策**: 位置情報を偽装するソフトや外部 GPS 機器を使っていると判定された場合、記録は作れません。
>
> 💡技術メモ: `CLLocation.sourceInformation` の `isSimulatedBySoftware` / `isProducedByAccessory` で判定しています。

### 4.2 ココカモ(周辺施設の検索)

「ココカモ」は「ここかも?」の意味で、**現在地から半径100m 以内の施設** を一覧表示し、タップするだけで施設名や住所を記録に入れられる機能です。施設名で絞り込むこともできます。

💡技術メモ: Apple の MapKit で検索しています。一時的なエラーには自動でリトライします。

### 4.3 後付け記録(アトヅケ)

現地で記録し忘れたときに、**後から日時と場所を指定して記録を作れる** 機能です。記録タブ右下の「＋追加」ボタンから使えます。

- ステップ1「日時と場所」: 場所の検索、地図をタップして選ぶ、**写真の位置情報・撮影日時から取り込む** のどれかで指定
- ステップ2「詳細情報」: 通常の記録と同じく、タイトルや写真などを入力(省略して保存も可)

後付け記録には「後付け」バッジが付き、通常の記録とは区別されます。

### 4.4 記録の種類(証明付き / 後付け)

| 種類 | 作り方 | 意味 |
|---|---|---|
| **証明付き記録** | ココキタボタンでその場で作成 | その時その場所にいたことが証明されている |
| **後付け記録** | 手入力・写真から作成 | 実際に行ったかどうかの証明はない |

証明付き記録の場所や日時は、後から書き換えられないように守られています(タイトルやメモなどは自由に編集可能)。

💡技術メモ: 記録の場所・日時などに、端末内の鍵で電子署名(P256 ECDSA)を付けています。データが書き換えられると署名の検証に失敗するため、改ざんを見つけられます。署名用の鍵は Keychain に保存しています。

### 4.5 自動記録

アプリを開いていなくても、**訪れた場所を iPhone が自動で検知し、「記録候補」として貯めておく** 機能です(オプション。初期設定はオフ)。ホーム画面のボタンか設定画面からオンにできます。

- 候補は後からまとめて確認し、「記録する」か「却下」を選ぶ
- 候補には到着日時・滞在時間が表示される
- 自宅や職場など、検知してほしくない場所は「この場所を自動検知しない」で除外できる
- 使うには、位置情報の権限を「常に許可」にする必要がある

💡技術メモ: iOS の Visit Monitoring(訪問検知)を利用しています。詳細は [auto-record-feature-design.md](features/auto-record/auto-record-feature-design.md)。

### 4.6 記録を見る・探す

記録タブでは、記録を3つの形で見られます。

- **一覧**: 新しい順 / 古い順に並べて表示
- **地図**: 記録した場所をピンで表示
- **日付**: カレンダーから日ごとの記録を表示

**検索・絞り込み** の条件:
- キーワード(タイトル・住所)
- ラベル / 旅行 / メンバー / 施設カテゴリ
- 期間(今日・昨日・今週・先週・今月・先月・期間指定)

記録の詳細画面では、地図・写真・施設情報のほか、**「近くの記録」「同じ旅行の記録」** も表示されます。地図アプリで開いたり、SNS などに共有したりもできます。

### 4.7 ラベル・旅行・メンバーの管理

メニューから、記録の分類に使う3種類のタグを管理できます。

| 種類 | 使い方の例 | 特徴 |
|---|---|---|
| ラベル | 「カフェ」「絶景」 | 11色から色を選べる |
| 旅行 | 「2026 京都旅行」 | 旅行・おでかけ単位でまとめる |
| メンバー | 「家族」「友人A」 | 一緒に行った人 |

タグを削除しても、記録そのものは消えません。各タグの詳細画面には、そのタグが付いた記録の一覧が出ます。

### 4.8 ゴミ箱

削除した記録は、すぐには消えずに **ゴミ箱に30日間保存** されます。期間内なら復元でき、30日を過ぎると自動で完全削除されます。手動で完全削除したり、ゴミ箱を空にしたりもできます。

### 4.9 データの初期化

設定の「すべてリセット」から、**すべての記録を端末から削除** できます。削除前に確認が出ます。この操作は元に戻せません。

💡技術メモ: データのバックアップ(ZIP 書き出し)とリストア(復元)の機能もありますが、**開発者専用** です。一般のユーザーは使えません。開くには、初期化画面での隠し操作と開発者パスワードが必要です。デバッグビルドでは開発者ツールからも開けます。

### 4.10 ブック

記録をテーマごとに分けて管理できる「ノート」のような仕組みです。最初は「マイブック」が1冊あり、**Premium プランでは複数のブックを作れます**。ブックごとに名前とカバーカラーを設定できます。ブックを削除すると、その中の記録やタグもすべて削除されます。

## 5. 聖地巡礼・コース機能

### 5.1 コースとは

「コース」は、テーマに沿って複数の **スポット**(訪れる場所)をまとめたものです。

| コースの種類 | 内容 |
|---|---|
| 巡礼 | アニメ・映画などの舞台をめぐる |
| スタンプラリー | スポットを回ってスタンプを集める |
| マイリスト | ユーザーが自分で作るコース |

コースのカテゴリ: 歴史・文化 / 自然 / アート・エンタメ / 映画・ドラマ / 旅行・観光 / アニメ・漫画 / 自作コース

運営が用意したコースはインターネットから自動で読み込まれ、新しいコースには「NEW」バッジが付きます。

### 5.2 コースの使い方

すべてのコースは最初から有効になっていて、特別な準備をしなくても、スポットで記録すれば達成になります。

1. コース一覧から気になるコースを選ぶ
2. コース詳細でスポットの一覧・地図・達成状況を確認する
3. 現地に行き、ココキタボタンで記録する
4. スポットの有効範囲内で記録すると **「聖地巡礼達成!」** になり、スタンプがもらえる
5. すべてのスポットを回ると **「コース全制覇」**

- コースやスポットは **お気に入り** に登録できる
- コースは「近い順」「更新日順」「スポット数順」「達成スポット数順」などで並べ替えられる
- 達成したら、写真や地図入りの画像で **SNS に共有** できる

### 5.3 過去の記録からの達成認定

コースの詳細を初めて開いたとき、**以前に作った証明付き記録の中にスポットの近くで記録したものがあれば、さかのぼって達成と認められます**(「過去の記録から巡礼スポット達成認定!」)。候補が複数ある場合などは、スタンプ画面からどの記録で獲得するかを選べます。

### 5.4 何人目の到達者か

スポットを達成すると、**「このスポットに訪れた◯人目です」** と表示されます。これは、各ユーザーの到達情報を匿名で集計して実現しています(6章参照)。

### 5.5 スタンプ

スタンプタブでは、集めたスタンプを一覧で見られます。

- スタンプの背景写真は、自分の写真や訪問記録の写真に変えられる
- スタンプと記録の紐づけを解除したり、候補の記録から手動でスタンプを獲得したりできる

### 5.6 スポット一覧

すべてのコースのスポットを、コースをまたいで一覧できます。

- 表示の切り替え: 近く / お気に入り / 行った / 都道府県別 / フォルダ
- スポットを自分で作った **フォルダ** に整理できる
- スポットの情報に誤りがあれば、アプリから **問い合わせ**(メール)ができる

### 5.7 自作コース(マイリスト)

自分でコースを作ることもできます。

- タイトル・説明・カバー画像を設定
- スポットの追加方法: **場所名で検索 / 地図から選ぶ / 写真の位置情報から / 自分の記録から / 緯度経度を直接入力**
- 「有効範囲」(何 m 以内で記録すれば達成とするか)をコース全体・スポットごとに設定できる
- 後付け記録を達成に含めるかどうかを選べる

### 5.8 再生機能(ツアーモード・シネマモード)【Premium】

コースを「再生」して楽しむ機能です。

- **ツアーモード**: 地図上でスポットを順番に自動でめぐる。説明文を1文字ずつ表示する演出もある
- **シネマモード**: スポットの写真をスライドショーで次々に表示する

表示時間や切り替えの速さを調整できます。

## 6. サーバー連携と匿名データ

ココキタの記録は基本的に **端末の中だけ** に保存されます。ただし、以下のために一部の情報を **匿名で** サーバーに送ります。

| 送る情報 | 何に使うか |
|---|---|
| 到達したスポット | 「◯人目」の表示、よく訪問されるスポットの集計 |
| コースの閲覧・お気に入り登録 | 人気コースの集計 |

- 送信されるのは個人を特定できない匿名の ID と、上の情報だけです
- 初期設定はオン。設定画面からいつでもオフにでき、**サーバーに送ったデータを削除** することもできます
- オフにしても記録機能は今までどおり使えます

💡技術メモ: Supabase の匿名認証を使用しています。詳細は [server-feature-design.md](features/server/server-feature-design.md)。

## 7. 料金プラン(Premium)

基本機能は無料で使えます(広告が表示されます)。**ココキタ Premium** に登録すると、次の機能が使えます。

| Premium 機能 | 内容 |
|---|---|
| 広告非表示 | 広告なしで使える |
| 複数ブック | テーマ別に複数のブックを作れる |
| コース再生 | ツアーモード・シネマモードが使える |

料金プラン: 月額($1.99) / 買い切り($19.99)(機種変更時は「購入を復元」で引き継げます)

## 8. はじめて使うとき(オンボーディング)

初回起動時は、次の3ページで案内します。

1. **聖地巡礼モード** の紹介
2. **記録モード** の紹介
3. **位置情報の許可** のお願い(匿名データ送信についての説明もここに表示)

その後は、ボタンの場所を吹き出しで教える **ガイド(コーチマーク)** が出ます。

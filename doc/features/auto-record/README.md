# 自動記録

> ステータス: 実装済
> 最終更新: 2026-11-24
> 対象バージョン: v3.x〜

## この機能について

位置情報をバックグラウンドで見守り、滞在した場所を「記録候補」として提示する機能。ユーザーが候補を確認してから訪問記録にする。除外エリアの設定にも対応している。

- `kokokita/Shared/Features/AutoRecord/` — 設定・候補検出のサービス
- `kokokita/Features/AutoRecordScreen/` — 候補確認画面

## このモックで従うもの
- 画面構成（ビジュアル → テキスト → インジケーター＋ボタン）と余白感
- 色（BrandAccent #4B4FD1 / BrandBackground #F6F4EF / 本文 #1B1B2F / サブ #55556A / 非アクティブ #D9D6E6）
- 文字の階層（アイブロウ 13pt / 見出し 30pt Black / 本文 15pt）
- ボタン、ページインジケーター、ページ3の匿名データ行（Toggle付き）の形

## このモックで従わないもの
- **ページ1・2のビジュアル部分（カードやアニメーション）**：仮のものです。実装では、実際のアプリ画面を録画した動画に置き換えます。再現して実装しないでください
- **文言**：すべて仮です。草案は別途作成してください
- フォント：モックは Noto Sans CJK で描画。実装はシステムフォントを使う
